## Invariants — uphold throughout the entire build

### No dxpy in `purple_plotter.py`

`purple_plotter.py` must never import `dxpy` or call the `dx` CLI. All DNAnexus
I/O belongs in `src/code.sh`.

**Verification:**
```bash
grep -n "import dxpy\|from dxpy\|subprocess.*dx " \
    resources/home/dnanexus/purple_plotter/purple_plotter.py
# Must produce no output
```

### `-u` flag must not appear in `code.sh`

`set -u` (undefined variable error) leaks into the DNAnexus job wrapper and causes
output upload to fail silently. Use `set -exo pipefail` — not `set -euxo pipefail`.

**Verification:**
```bash
grep "set -" src/code.sh
# Must show:  set -exo pipefail
# Must NOT show: set -euxo pipefail or set -u
```

### At-least-one input guard must fire before Python is called

The validation check (`purple_tar` and `cnvkit_cnr` both absent → exit 1) must appear
in `code.sh` **before** `dx-download-all-inputs` and before calling Python.

**Verification:**
```bash
# Check order of lines in code.sh
grep -n "Validating\|dx-download\|ppenv" src/code.sh
# Validating line number must be lower than dx-download-all-inputs line number
```

### Empty-string graceful degradation, not None/missing key errors

When any optional input is absent, the corresponding bedgraph/SEG string must be `""`
(empty string), not `None`. The HTML template must receive a value for every
`{placeholder}` — a `KeyError` on template formatting is a hard failure.

**Verification:**
```bash
# CLI with only cnvkit_cnr — should exit 0
python3 resources/home/dnanexus/purple_plotter/purple_plotter.py \
    --sample TEST \
    --cnvkit_cnr tests/test_data/sample.cnr \
    --output_dir /tmp/
echo "Exit: $?"
# Expected: Exit: 0
```

### No AI attribution in commits or files

Do not add "Generated by", "Co-authored by AI", or any similar attribution to
commit messages, README, or source files.

## Context — where this code comes from

The data conversion functions (`coverage_log2_bedgraph`, `cn_bars_by_state`,
`baf_bedgraph`, `baf_bedgraph_mirror`, `baf_seg_bars_by_state`, `to_seg`,
`cnr_to_bedgraph`, `cns_to_seg`, `genemetrics_to_bedgraph`) and the `HTML_BARS`
template are extracted verbatim from:

```
cnv-backbone-purple-atlas/scripts/igv_bars.py
```

Copy them without modification into `purple_plotter.py`. They are already pure
(DataFrame → string) with no DNAnexus dependency — do not refactor them unless a
test fails because of a bug.

The key change is replacing the `CohortConfig`-based data-fetching (`dx cat`,
`dx find data`) with simple `load_*` functions that read local file paths.
